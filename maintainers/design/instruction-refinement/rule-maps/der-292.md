## Meaning questions

Resolved from the text:

- **MQ1** (LLD Repeats, "Regression = fewer passes … on any model,
  task, item"): the LLD counts "C items and Completed as passes out of
  3" and bars only tokens and wall time as a pass bar, so Completed is
  an item for the regression rule (`procedure.md` Scoring 4).
Resolved by the operator:

- **MQ2** (scorer `person`), operator clarification 2026-09-27: "a
  person" means the operator, or someone the operator names in writing
  (`procedure.md` Scoring 2).

Resolved by the manager:

- **MQ3** (LLD Run setup, reply mode (b): the agent stops to ask although
  every reply was given up front), manager clarification 2026-09-27: the
  runner sends exactly one follow-up turn, "Continue: the replies above
  answer your question."; C1 is scored on whether the agent asked where
  required. A second stop ends the repeat, as the card's one-`Continue.`
  rule does in mode (a) (`procedure.md` Scripted replies).
