## Modifications

These guides were modified. The only change: every inline reference of
the form `npx -y modern-web-guidance@latest retrieve "<id>"` was replaced
with a relative Markdown link to the local guide file with that id,
written `[<id>](<relative path>)`. That is 198 references on 164 lines
in 65 files, pointing to 99 guides. No other text, code example, support
note or fallback was changed.
