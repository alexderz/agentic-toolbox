# Model research

This space tracks which open-weight models can do real agent work on one
local machine, how fast they run, and with what settings. It covers every
model we tested, every model we dropped, and every model we checked and
found does not fit, so nobody researches the same model twice.

The machine is **Titan**: one NVIDIA RTX 3090 (24 GB), 125 GB of system
RAM, models served one at a time through llama-swap. For the full setup,
see [Method](method.md).

## How to use this space

- To pick a model for a job, start with [Conclusions](conclusions.md).
- To check a model you just heard about, find it in the index. If it is
  there, its card says what we found and whether it is worth another look.
- To understand a number, read [Method](method.md). Results are a living
  snapshot, not an apples-to-apples benchmark: the tests changed over time
  (see [History](history.md)), each model ran at its own best fit on the
  card, and each row is one run.
- For engine choice and settings, see [Engines](engines.md).
- For dated findings and decisions, see the [Research log](log.md).
- For a creative-writing comparison (a short story and the model's own edit), see the
  [Story test](story-test/README.md).

## Status labels

| Status | Meaning |
| --- | --- |
| Recommended | Passed test 2 and is a current pick for its role. |
| Tested | Ran through the tests; usable, not a current pick. |
| Downloaded, not tested yet | Weights are on the NAS; no graded run yet. |
| Dropped | Ran and failed, or was clearly worse than an alternative. |
| Does not fit | Checked and cannot run on this machine as released. |
| Needs an engine update | Fits, but no engine we run supports its architecture yet. |
| Watching (no weights yet) | Announced; no public weights to test. |

A model marked **Uncensored** has refusals removed (fine-tuned, abliterated,
or Heretic-processed). We run those for security testing of our own
software, through the same coding tests as every other model.

## How this space is maintained

The model cards and the index are generated from the graded bake-off
results. The other pages are written by hand. New results, new candidates,
and rejected models are added as they come in.
