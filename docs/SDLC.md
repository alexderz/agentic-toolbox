# Software-building playbook (SDLC)

The software-building playbook is the existing SDLC workflow in
Workshop's shared Agentic Toolbox. Its machine skill ID remains `sdlc`: read
[skills/sdlc/SKILL.md](../skills/sdlc/SKILL.md). Asking the operator is
[skills/sdlc/SKILL.md#asking-the-human](../skills/sdlc/SKILL.md#asking-the-human).
Step files are in `skills/sdlc/references/`; intake is
`skills/sdlc/references/intake.md`.

This compatibility entry point remains available. Workbench (formerly
SoloDLC) is a consuming application, not the name of this playbook.
